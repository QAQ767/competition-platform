# 竞赛同行 · 前端

高校竞赛组队与训练平台的 Vue 3 前端，使用 Vite、Element Plus、Pinia 和 Vue Router。

## 本地运行

```sh
npm ci
npm run dev
```

默认访问 `http://localhost:5173`，`/api` 与 `/ws` 代理到本地 8080 端口。完整后端和 Docker 启动步骤见上级目录的 README。

```sh
npm run build
npm run preview
```

`preview` 用于检查构建后的静态页面，完整业务联调请使用带代理的开发服务或 Docker 部署。

## 界面结构

- `src/styles/theme.css`：全局色彩、字体、组件外观与基础响应式规则。
- `src/App.vue`：分组侧边导航、移动端菜单、通知和账号入口。
- `src/components/PageHeading.vue`：统一的页面标题与说明。
- `src/views/Home.vue`：竞赛发现页、赛事卡片、筛选、报名时间提示，以及加载、空结果和失败重试状态。
- 组队广场展示成员进度与技能标签；训练中心保留资源、收藏、打卡和排行；登录页使用双栏布局。

界面装饰使用本地 SVG、CSS 和已有图标库，无需外部图片或字体服务。现有后端接口与权限逻辑保持兼容。

## 本次界面验收

生产构建通过。通过浏览器模拟接口检查了竞赛搜索与组队跳转、空结果重置、失败重试、登录后通知刷新、资源收藏、训练打卡和移动导航，并检查桌面、平板与手机布局。浏览器验证数据只用于本地验收，不包含在应用中。

本次环境没有启动后端，因此未覆盖真实数据库、账号认证和 WebSocket 服务联调。构建仍有现有依赖的大文件提示，后续可独立优化依赖按需加载。
