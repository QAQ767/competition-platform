# 赛事发现模块已移除

2026-11-01：小智新增管理员只读联网赛事搜索，详见 [全站小智说明](global-assistant.md)。原后台发现作业、草稿和发布接口继续保持删除状态；赛事仍由管理员手动录入。下文为10月31日范围调整记录。

2026-10-31 按项目范围调整，移除管理员赛事发现功能：联网搜索、公告 URL 抓取、公告文本提取、发现作业和赛事草稿审核发布；相关前后端代码和搜索环境变量已删除。

赛事由管理员在“后台管理 → 竞赛管理 → 新增竞赛”中手动录入。学生端“发现竞赛”的查询、筛选与小智对话推荐继续使用平台已有赛事目录。训练学习助手继续保留。

旧的 `/api/admin/competition-discovery/**` 与 `/api/admin/competition-drafts/**` 不再提供服务。新库不再创建发现模块的四张表；已有数据库中的历史表不会自动删除，不影响当前业务，也不会被应用读取。

历史验收文档保留用于追溯。当前范围为“小智辅助管理员联网查找赛事、管理员手动维护赛事”，不承诺自动采集入库或发布。正式开题材料和答辩文件本次未修改。
