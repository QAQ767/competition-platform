# 全站小智（2026-11-01）

小智由 App.vue 全局挂载。任何页面均可展开，切换路由、收起窗口不取消回答；“停止”、新建对话和退出登录停止前端接收。训练资源“问小智”打开同一个窗口并传入资源信息。

## 能力与权限

- 平台赛事和队伍推荐：复用现有推荐服务、真实卡片、资格过滤和 Redis 会话。
- 学习与一般问答：复用原有流式接口，支持知识讲解、代码分析、练习题、训练计划及解释此前结果。
- 管理员联网赛事搜索：先检索网页，再依据证据整理赛事。显示来源链接、网页发布时间和查询时间；不会自动录入赛事库。
- 非管理员直接调用搜索接口返回403。权限由后端登录态判断，不依赖模型或浏览器声明。

`POST /api/assistant/route` 根据问题和最近对话返回 ADVICE、LEARNING、SEARCH 或 DENIED。模型分类最多15秒，失败使用保守规则。管理员“帮我找最近的高校竞赛”默认联网，明确“平台内”则查本地目录；追问补全指代，换话题切换能力。

## 搜索配置

`POST /api/assistant/search` 默认调用 DeepSeek Search API，并请求正文。仅服务端配置：

```dotenv
ASSISTANT_SEARCH_URL=https://api.deepseek.com/v1/tools/search
# 留空时复用 DeepSeek 模式的 LLM_API_KEY
ASSISTANT_SEARCH_API_KEY=
```

自定义地址仅用于兼容协议的可信服务端或本地测试。搜索最多6条、超时25秒，整理最多40秒；鉴权、余额、限流及网络错误明确显示。默认近期按未来30天理解；公告发布日期、报名截止、比赛日期分别处理，缺失信息标注待核实。搜索结果可能含往届或聚合页信息，报名条件应核对原文。

## 会话与边界

当前账号最近20条成功消息和推荐会话ID保存在 `xiaozhi-global-{用户ID}`。最近10条消息（每条最多3000字，含卡片摘要）用于分流及学习追问。退出或切换账号清理当前缓存，新建对话删除对应推荐会话。旧版页面历史不自动合并。

搜索和分流为短时同步请求。停止后浏览器不再接收，已发出的搜索或分类可能继续执行到超时；迟到结果不会写回新对话。推荐保留原有服务端取消能力，学习流保留断连检测。

未恢复旧后台发现作业、抓取队列、草稿审核或发布模块。赛事录入继续使用管理员手动表单。
